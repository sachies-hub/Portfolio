# Steward Chirenga — Portfolio

A single-page portfolio site (Hero, About, Skills, Projects, Contact) built with plain HTML/CSS/JS — no build step required.

## How to use
- Open `index.html` directly in any browser, or
- Host it for free on GitHub Pages, Netlify, or Vercel by uploading this folder.

## Before you publish
Search the file for `GITHUB_PROFILE_URL` (appears on each project card's GitHub icon) and replace it with your real GitHub profile link, e.g. `https://github.com/your-username`.

You may also want to:
- Swap the "VIEW PROJECT ↗" `#` links with real project URLs.
- Add a real resume link if you want a "Download Resume" button.
- Replace the LinkedIn / Instagram / Facebook `#` links in the footer with your real profiles.

## Structure
Everything (HTML, CSS, JS) lives in `index.html` — no external files or dependencies besides Google Fonts (Space Grotesk, JetBrains Mono, Inter), loaded via CDN link in the `<head>`.
